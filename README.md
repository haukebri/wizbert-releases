# Wizbert

Your wizard companion for games and everyday adventures.

[Download Wizbert for macOS](https://github.com/haukebri/wizbert-releases/releases/latest/download/Wizbert-mac-arm64.dmg) · [Release notes](https://github.com/haukebri/wizbert-releases/releases/latest) · [Website](https://wizbert.com/)

## Requirements

Apple Silicon Mac, macOS 14 or later, internet connection, and an existing Wizbert account. Public signup, Windows, Intel Mac and mobile versions are not available.

## Install

Open the DMG and drag **Wizbert** into **Applications**. This early release is **unsigned and not notarized by Apple**. If macOS blocks the first launch and you trust this download, follow [Apple’s instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445). Do not disable Gatekeeper globally.

## Updates

Choose **Wizbert → Check for Updates…**. If a newer version is available, open its download page, download the DMG, quit Wizbert when ready, and replace the app in Applications. Update checks do not install anything or restart the app. Settings and account data are stored separately from the application bundle.

Local speech features require additional setup; text replies remain available.

This repository contains official distribution artifacts and release notes. Application source is private. Published assets and tags are immutable. Each release includes update metadata, SHA256 checksums and source-commit provenance.
