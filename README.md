# Wizbert

Your wizard companion for games and everyday adventures.

This repository hosts official Wizbert installers, update metadata, and release notes. Application source is maintained privately.

## macOS

Wizbert supports Apple Silicon Macs running macOS 14 or later. The first signed production release is being prepared; no production installer is available yet.

When available, install by opening the DMG and dragging Wizbert to Applications. Updates are available from the Wizbert menu; downloading and restarting require your confirmation.

Visit [wizbert.com](https://wizbert.com/) for product information.
